## Installing version 1

GW v1 packages (conda, Homebrew, desktop installers) are still available — see
[Install (v1)]({{ site.baseurl }}/v1/install/Install.html). GW v2 is in beta and not yet in
package managers, so it must be [built from source]({{ site.baseurl }}/install.html).
